# Contributing

Welcome to Project Academy.

---

# Philosophy

We build educational software with the quality of a modern video game.

Every contribution must improve at least one of these areas:

Learning

Motivation

Teacher Experience

Academy Experience

Code Quality

---

# Before Coding

Always read the documentation.

Never implement features without understanding the product.

---

# Commit Messages

Examples

feat(auth): add academy login

fix(game): snake collision bug

docs(domain): update learning unit

refactor(api): improve authentication

---

# Pull Requests

Every Pull Request should explain:

What changed

Why it changed

Possible impacts

Testing performed

---

# Code Review

Every feature should respect:

Architecture

Naming conventions

Documentation

Testing

Performance

Maintainability

---

# Final Rule

Readable code is more valuable than clever code.
