# Academy Domain

Version: 1.0

Status: Draft

Author: Project Academy Team

---

# Purpose

An Academy represents an educational institution that uses Project Academy to teach languages through gamification.

Each academy operates independently while sharing the same platform infrastructure.

Academies can customize their identity without modifying the core learning or game systems.

---

# Academy Structure

An academy contains:

- Branches
- Teachers
- Students
- Lesson Designers
- Administrators
- Courses
- Classes
- Events
- Branding
- Reports

---

# Multi-Tenant Architecture

Each academy is completely isolated.

Academies cannot access:

- Students from other academies
- Teachers from other academies
- Courses from other academies
- Reports from other academies
- Rankings from other academies

Data isolation is mandatory.

---

# Branches

An academy may contain one or multiple branches.

Example

St George English School

├── Brisbane
├── Gold Coast
├── Sydney

Each branch may have:

- Different teachers
- Different schedules
- Different classrooms
- Different students

All branches belong to the same academy.

# Courses

An academy manages:

Courses

↓

Levels

↓

Classes

↓

Lessons

Students progress through levels according to teacher evaluation.

Students never permanently fail.

If additional practice is needed,

they remain at the current level.

---

# Attendance

Teachers register attendance.

Attendance grants:

- XP
- Coins
- Attendance streaks
- Weekly missions

Attendance becomes part of progression.

---

# Rankings

Weekly Ranking

Top Coins

---

# Academy Permissions

Academies CAN:

- Create teachers
- Register students
- Create courses
- Assign classes
- Schedule lessons
- Register attendance
- Create internal events
- Customize branding

Academies CANNOT:

- Modify XP economy
- Modify game balance
- Create premium items
- Modify global rankings
- Change platform rules
- Access other academies

---

# Academy Onboarding

The onboarding process is:

1. Academy subscribes.

2. School Owner account is created.

3. Branding is configured.

4. Branches are created.

5. Teachers are invited.

6. Courses are configured.

7. Students are imported or registered.

8. First lesson is published.

9. Academy goes live.

---

# Academy Principles

1. Every academy has its own identity.

2. Every academy owns its data.

3. Teachers remain essential.

4. Students belong to an academy.

5. Branding is customizable.

6. The game engine is shared.

7. Learning standards remain global.

8. The academy experience should feel unique.

9. Gamification enhances education.

10. Project Academy grows together with every academy.
