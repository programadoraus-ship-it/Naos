# Course Instance Domain

Version: 1.0

Status: Draft

Author: Project Academy Team

---

# Purpose

A Course Instance represents a real class being taught by a teacher.

It is created from a Course Template.

Students never enroll in templates.

Students enroll in Course Instances.

---

# Philosophy

One template.

Many classes.

Many teachers.

Many schedules.

A Course Template is reusable.

Each Course Instance is unique.

---

# Example

Template

English Beginner A1

↓

Teacher creates

---

# Course Instance Information

Every Course Instance stores:

- Name
- Academy
- Branch
- Course Template
- Teacher
- Classroom
- Schedule
- Start Date
- End Date
- Status

---

# Students

Students join a Course Instance.

Every student keeps:

- Personal progress
- XP
- Coins
- Inventory
- Attendance
- Completed Learning Units
- Statistics

---

# Learning Units

The Course Instance follows the Course Template.

Teachers decide when to unlock each Learning Unit.

Students cannot unlock units by themselves.

---

# Unlock Workflow

Teacher finishes today's class

↓

Teacher unlocks Learning Unit

↓

Students receive notification

↓

Students complete activities

↓

Teacher reviews progress

↓

Teacher unlocks next Learning Unit

---

# Teacher Controls

Teachers can:

- Unlock Learning Units
- Lock Learning Units
- Assign homework
- Create assessments
- Schedule quizzes
- Register attendance
- Review student progress
- Send announcements

Teachers cannot modify the original template.

---

# Attendance

Attendance belongs to the Course Instance.

Each class session records:

- Present
- Late
- Excused
- Absent

Attendance grants progression rewards.

---

# Assessments

Teachers may create:

- Homework
- Quizzes
- Speaking Tests
- Writing Tasks
- Listening Tests

Results become part of the student's progress.

---

# Progress Dashboard

Teachers can monitor:

- Student progress
- XP earned
- Attendance
- Average score
- Completed Learning Units
- Pending activities

---

# Notifications

Students receive notifications when:

- A Learning Unit is unlocked
- Homework is assigned
- An assessment is available
- A class is cancelled
- Rewards are earned

---

# Course Completion

A Course Instance finishes when:

- All Learning Units are completed
- Final assessment is finished
- Teacher marks the course as completed

Students keep:

- XP
- Inventory
- Achievements
- Statistics
- Certificates (if applicable)

---

# Design Principles

1. Templates are permanent.

2. Course Instances are temporary.

3. Students belong to Course Instances.

4. Teachers control progression.

5. Learning follows classroom teaching.

6. Attendance matters.

7. Progress is measurable.

8. Every class is independent.

9. Templates remain reusable.

10. Every student keeps their personal journey.
