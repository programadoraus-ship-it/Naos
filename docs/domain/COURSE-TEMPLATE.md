# Course Template Domain

Version: 1.0

Status: Draft

Author: Project Academy Team

---

# Purpose

A Course Template defines the educational structure of a course.

It contains the curriculum, Learning Units, suggested activities and progression rules.

Templates are reusable.

Teachers never modify the original template.

Instead, they create Course Instances from it.

---

# Philosophy

Create once.

Teach many times.

A Course Template should be reusable across multiple academies, teachers and classes.

---

# Template Structure

A Course Template contains:

- Course Information
- Language
- Level
- Learning Units
- Suggested Release Plan
- Suggested Assessments
- Suggested Mini Games
- Learning Objectives

---

# Ownership

Templates may be created by:

Project Academy

or

An Academy

Templates created by Project Academy are read-only.

Academy Templates belong only to that academy.

---

# Customization

Academies may duplicate a template.

After duplication they can:

Rename units

Add units

Remove units

Change activities

Change assessments

Keep academy-specific content

The original template remains unchanged.

---

# Course Instance

Templates are never assigned directly to students.

Teachers create Course Instances.

Example

Template

↓

English Beginner A1

↓

Instance

↓

Monday Evening Class

↓

Teacher Sarah

↓

18 Students

↓

Starts February 10

Students interact only with the Course Instance.

---

# Design Principles

1. Templates are reusable.

2. Templates never belong to students.

3. Teachers teach Course Instances.

4. Templates support versioning.

5. Every academy may customize its own copy.

6. Learning Units remain modular.

7. Templates support multiple languages.

8. AI assists template creation.

9. Templates evolve without breaking existing courses.

10. Templates reduce repetitive work.
