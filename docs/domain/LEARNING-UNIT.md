# Learning Unit Domain

Version: 1.0

Status: Draft

Author: Project Academy Team

---

# Purpose

A Learning Unit represents a topic taught by the academy.

The Learning Unit is the central educational element of Project Academy.

Every lesson, mini-game, assessment and activity belongs to a Learning Unit.

Students cannot freely unlock new units.

Teachers control the learning pace.

---

# Philosophy

Project Academy complements classroom learning.

The platform never replaces the teacher.

Students learn a topic in class.

Then they reinforce that topic inside the platform through games and activities.

---

# Learning Flow

Teacher explains a topic

↓

Teacher unlocks the Learning Unit

↓

Students receive access

↓

Students complete activities

↓

Students earn XP

↓

Students improve

↓

Teacher evaluates progress

↓

Teacher unlocks the next Learning Unit

# Unlock System

Learning Units are locked by default.

Only authorized teachers can unlock them.

Unlocking may occur:

- For one class
- For multiple classes
- For an entire course

Students cannot unlock units by themselves.

---

# Progression

A student cannot skip Learning Units.

Units follow the academy curriculum.

Progress depends on teacher decisions.

---

# Review Mode

Completed Learning Units remain available.

Students can replay:

- Lessons
- Mini-games
- Quizzes
- Pronunciation
- Practice activities

Reviewing content continues rewarding learning, but with balanced XP to prevent abuse.

---

# Teacher Control

Teachers decide:

- When to unlock a unit
- Which classes receive it
- Deadlines
- Optional activities
- Mandatory assessments

---

# Game Integration

Every Learning Unit automatically connects with the Game Engine.

Available mechanics may include:

- Snake Words
- Sentence Maze
- Memory Match
- Escape Room
- Detective Challenge
- Karaoke
- Pronunciation Battle
- Listening Challenge
- Boss Battle

The mechanics are reusable.

Only the educational content changes.

---

# Rewards

Completing a Learning Unit may grant:

- XP
- Coins
- Badges
- Titles
- Cosmetics
- Achievement progress

---

# Design Principles

1. Teachers control progression.

2. Learning follows the classroom.

3. Students never run out of practice.

4. Games reinforce learning.

5. Every unit feels like a mission.

6. Review is always encouraged.

7. The same mechanics can teach different topics.

8. The platform supports different teaching speeds.

9. Learning Units are the foundation of the educational system.

10. Fun supports learning, never replaces it.
