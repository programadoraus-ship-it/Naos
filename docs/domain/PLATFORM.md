# Purpose

Project Academy is a multi-tenant educational gaming platform.

The platform serves two types of customers:

- Educational institutions (Academy Edition - B2B)
- Independent learners (Community Edition - B2C)

Both editions share the same core platform, game engine, learning engine and AI services.

---

# Core Modules

The platform is composed of the following core systems:

- Authentication
- Academy Management
- Community
- Learning Engine
- Game Engine
- Reward Engine
- Progression Engine
- AI Engine
- Analytics
- Notifications
- Subscription & Billing

---

# Platform Principles

- One platform.
- Multiple academies.
- Multiple branches.
- Multiple languages.
- Shared game engine.
- Personalized academy experience.
- Real teachers remain essential.
- Gamification supports learning.
- AI assists, never replaces teachers.

---

# Supported Editions

## Academy Edition

Designed for schools and language academies.

Includes:

- Branding
- Teachers
- Students
- Courses
- Attendance
- Reports
- Academy Rankings

---

## Community Edition

Designed for independent learners.

Includes:

- Personal progression
- AI tutor
- Global rankings
- Missions
- Public events
