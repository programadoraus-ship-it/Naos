# GAME ECONOMY

Version 1.0

---

# Philosophy

Everything inside Project Academy is earned.

Never bought.

Students progress because of effort.

Not because of money.

---

# Core Resources

The platform contains four primary resources.

## Experience (XP)

Represents learning progress.

XP increases:

- Player Level
- Academy Rank
- Seasonal Progress

XP can never be purchased.

---

## Coins

Used to purchase cosmetics.

Coins are earned through:

Lessons

Mini Games

Attendance

Achievements

Events

Daily Missions

Weekly Missions

---

## Gems (Future)

Premium currency.

Only obtainable through:

Special events

Official competitions

Academy rewards

Never sold.

---

## Tickets

Used to enter tournaments.

Generated weekly.

Cannot be purchased.

# How XP is Earned

Students earn XP from:

✔ Completing Learning Units

✔ Mini Games

✔ Pronunciation Practice

✔ Listening Activities

✔ Homework

✔ Daily Missions

✔ Weekly Missions

✔ Class Attendance

✔ Academy Events

✔ Helping Complete Academy Challenges (future)

---

# XP Rules

XP rewards consistency.

Not repetition.

Example:

First completion

100 XP

Second completion

40 XP

Third completion

15 XP

After many repetitions

5 XP

This prevents farming.

# Anti-Abuse Rules

Students cannot repeatedly farm XP.

Repeated activities provide reduced rewards.

Teachers validate attendance.

Events have participation limits.

Daily missions reset every day.

---

# Design Principles

1. Everything is earned.

2. No Pay To Win.

3. Cosmetics only.

4. Learning generates rewards.

5. Teachers generate opportunities.

6. Competition remains fair.

7. Attendance matters.

8. Progress feels meaningful.

9. Every reward tells a story.

10. Students always have a reason to return.
