# Purpose

The Progression System defines how students grow inside Project Academy.

Progress should always feel meaningful.

Students should always have another goal to pursue.

Progress represents effort, consistency and learning.

---

# Core Philosophy

Learning creates progress.

Progress creates motivation.

Motivation creates consistency.

Consistency creates learning.

---

# Three Progression Systems

Project Academy contains three independent progression systems.

1. Player Level

2. Competitive Rank

3. Prestige

Each system serves a different purpose.

---

# Player Level

Represents total lifetime experience.

Player Level never resets.

Player Level never decreases.

XP increases Player Level.

Higher levels unlock:

- Cosmetics
- Profile Frames
- Pets
- Titles
- Animations
- Avatar Items

---

# Competitive Rank

Represents current season performance.

Ranks reset every season.

Ranks encourage healthy competition.

Example

Bronze

↓

Silver

↓

Gold

↓

Platinum

↓

Diamond

↓

Master

↓

Grandmaster

↓

Legend

Students compete against others with similar progress.

---

# Prestige

Prestige represents long-term dedication.

Prestige never resets.

Prestige is earned through milestones.

Examples

Complete Beginner Course

Complete Intermediate Course

365 Day Attendance

100 Learning Units Completed

Perfect Pronunciation Master

Prestige grants permanent recognition.

---

# Learning Progress

Every Learning Unit completed contributes to:

Player Level

Achievements

Course Progress

Certificates

Academy Statistics

Teacher Reports

Learning is always the primary progression.

---

# Daily Progress

Every day students can progress by:

Attending class

Completing lessons

Playing mini-games

Practicing pronunciation

Completing missions

Daily Login

Helping complete academy events

---

# Weekly Progress

Weekly goals include:

Attendance

Homework

Leaderboard

Weekly Missions

Weekly Challenge

Weekly Chest

---

# Monthly Progress

Monthly goals include:

Student of the Month

Academy Ranking

Season Rewards

Exclusive Cosmetics

Community Events

Special Titles

---

# Long-Term Progress

Examples:

Complete all English levels.

Collect every pet.

Unlock every title.

Master every mechanic.

Complete every achievement.

Reach maximum prestige.

Become Academy Legend.

---

# Progress Visibility

Students should always see:

Current Level

XP Progress

Rank

Current Learning Unit

Achievements

Attendance Streak

Daily Missions

Weekly Missions

Season Progress

Nothing should feel hidden.

---

# Anti-Frustration Rules

Students should never feel stuck.

Every session should provide progress.

Even small victories matter.

Examples:

+ XP

+ Coins

+ Achievement Progress

+ Daily Streak

+ Collection Progress

---

# Graduation

Finishing a course does not finish the journey.

Graduation unlocks:

Next Course

Special Certificate

Graduation Cosmetics

Prestige Progress

Advanced Challenges

---

# Design Principles

1. Progress never stops.

2. Learning always matters.

3. Competition stays fair.

4. Long-term players receive recognition.

5. New players never feel left behind.

6. Every session creates progress.

7. Every achievement tells a story.

8. Every reward has meaning.

9. Prestige celebrates dedication.

10. Learning remains the ultimate goal.
