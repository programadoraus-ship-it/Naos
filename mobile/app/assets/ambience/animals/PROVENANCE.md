# Animals preview artwork

All seven PNGs in this directory were generated specifically for the NAOS Animals preview with OpenAI image generation on 20 September 2026. They are original generated assets, not downloaded third-party artwork. No external attribution, license file, paid resource, or runtime download is required.

- `woodland.png`: shared stationary woodland meadow with trees, hills and morning light.
- `fox.png`, `deer.png`, `owl.png`: transparent friendly character illustrations for Fox Grove, Deer Meadow and Owl Canopy.
- `butterflies.png`, `foliage.png`, `pawprints.png`: transparent foreground habitat details shared by the scenes.

The prompts specified a cohesive polished storybook/3D-rendered illustration style, transparent cutouts for foreground elements, no text or logos, and a separate landscape background. Characters and details are composited by Flutter; no foreground asset contains an opaque background.
