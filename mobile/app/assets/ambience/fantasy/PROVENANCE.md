# Fantasy preview assets

The seven PNGs in this directory were generated specifically for the NAOS local
institution-template preview with OpenAI's built-in image generation tool on
2026-09-21. They contain no third-party artwork, purchased resources, fonts,
logos, or stock imagery. The foreground PNGs have transparent backgrounds;
`valley.png` is the one shared full-bleed background for all three scenes.

Prompt set: an elegant painterly 3D-prerendered twilight fantasy valley;
isolated floating castle, magical book, friendly lavender dragon, glowing
mushrooms, fireflies, and crystal lantern, all in a consistent violet/gold
educational-fantasy direction. Each foreground prompt required genuine alpha,
complete silhouettes, no text and no watermark.

These are prerendered 2D images, not real-time 3D assets. The scene animation is
performed by Flutter transforms on whole images; the background remains still.
