# Space ambience assets

These seven original PNG illustrations were generated for NAOS with OpenAI's built-in image generation tool on 2026-09-20. No third-party artwork, fonts, or stock licenses were incorporated. Assets are used only in the local onboarding preview. The background (`starfield.png`) is reused unchanged by the three scenes; the other PNGs retain transparent alpha and are independent editable layers.

| File | Intended layer |
| --- | --- |
| `starfield.png` | stationary shared background |
| `planet.png` | Planet Exploration protagonist |
| `station.png` | Orbital Station protagonist |
| `asteroids.png` | Asteroid Expedition protagonist |
| `ship.png` | companion explorer craft |
| `probe.png` | companion scientific satellite |
| `stardust.png` | sparse luminous detail |

Generation brief: premium friendly illustrated space, painterly 3D-prerendered volume in indigo/teal/violet with subtle gold light; independent foreground subjects isolated on genuinely transparent backgrounds, no lettering or UI. The landscape brief specified low-contrast central negative space for interface legibility and recognizable nebula detail around the perimeter. Each asset was generated directly, not cut out of a flattened composite. Raster illustrations are prerendered images, not real-time 3D.
