# Bundled font attribution

The fonts in this directory are distributed under the SIL Open Font License
1.1 (OFL). The corresponding `OFL-*.txt` file is retained beside each family.
All files were obtained from the official Google Fonts repository:
https://github.com/google/fonts

| Family | Local files | Google Fonts directory |
| --- | --- | --- |
| Inter | `Inter-Variable.ttf` | `ofl/inter` |
| Lora | `Lora-Variable.ttf` | `ofl/lora` |
| Space Mono | `SpaceMono-Regular.ttf`, `SpaceMono-Bold.ttf` | `ofl/spacemono` |
| Nunito | `Nunito-Variable.ttf` | `ofl/nunito` |
| Fredoka | `Fredoka-Variable.ttf` | `ofl/fredoka` |
| Playfair Display | `PlayfairDisplay-Variable.ttf` | `ofl/playfairdisplay` |
| Poppins | `Poppins-Regular.ttf`, `Poppins-Bold.ttf` | `ofl/poppins` |
| Quicksand | `Quicksand-Variable.ttf` | `ofl/quicksand` |
| Montserrat | `Montserrat-Variable.ttf` | `ofl/montserrat` |
| Bitter | `Bitter-Variable.ttf` | `ofl/bitter` |

The ambience illustrations are original Flutter `CustomPainter` artwork and
do not include third-party graphical assets.
